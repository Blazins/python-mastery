Phase −1

Python Mastery

Python is not the subject here — it is the notation. The subject is problem-solving: recognising what a real problem actually needs, and expressing that solution correctly. Each chapter opens with a problem a working developer genuinely encounters, and teaches whatever that problem requires.

How to use this

Each chapter is read here, in the browser. The exercises are then written and run in a real editor and a real terminal — micro for writing, python3 for running, pytest for grading. The two surfaces are deliberate: a textbook for learning, a workshop for doing.

Chapter content is self-sufficient. Everything an exercise needs has been taught, either in that chapter or in one before it. If something in an exercise seems to require a tool that has never appeared, check the syllabus map — if it is not listed there, that is a gap in the syllabus, not in you, and it should be flagged rather than worked around.
